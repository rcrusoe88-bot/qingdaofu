# 四象主题（已选定）

清道夫 UI 的 hero 从「行星」换成「四象」：四枚圆章同属一套青铜掐丝，只换中心母题。
每枚对应一个页签，页签切换时整页底色、氛围光和圆章一起变化。

| 页签 | 四象 | 方位 / 季节 / 五行 | 寓意 | 当前状态 |
|---|---|---|---|---|
| 清理 | 白虎 | 西 / 秋 / 金 | 肃清 | 已启用 |
| 分析 | 青龙 | 东 / 春 / 木 | 洞察 | 已启用 |
| 记录 | 玄武 | 北 / 冬 / 水 | 封藏 | 已启用 |
| 状态 | 朱雀 | 南 / 夏 / 火 | 生机 | 已启用 |

## 动效

- 圆章本身不旋转，避免神兽倒立。
- `symbol-breath`：8 秒一次的极轻缩放（1 → 1.014），像呼吸。
- 外圈一条很淡的高光弧 18 秒绕行一圈，像金属边缘在灯下转过。
- `prefers-reduced-motion` 下两者都停止。

## 分析页（参考 Mole）

- 左侧：青龙圆章、当前总量、`当前目录 / 最大文件 / 卸载残留`、目录列表。
- 主区：面包屑、`文件 / 已用`、`多选 / 重新扫描`、树图。
- 树图：squarified 布局，面积 = 体积；点击目录下钻，面包屑回退；小于 0.6% 的条目合并成「其他」。
- 右键：复制路径 / 在资源管理器中显示 / 移到回收站（确认后进回收站）。
- 后端：`internal/analyze` 单次遍历聚合，60 秒上限，只读；`RecyclePath` 拒绝盘符根、系统目录、用户目录根和程序自身目录。
- 截图：`screens/analyze-mole.png`。

## 窗口

- `Frameless: true`：顶栏就是拖拽区，页面渐变一直铺到窗口上边缘，不再有浅色原生标题条。
- 右侧自绘最小化 / 最大化 / 关闭；关闭走 `runtime.Quit`，仍会触发 `OnBeforeClose`。
